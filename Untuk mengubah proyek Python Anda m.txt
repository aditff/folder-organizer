Untuk mengubah proyek Python Anda menjadi file 
.exe berdasarkan struktur folder yang terlihat di gambar (menggunakan PyInstaller), Anda bisa memanfaatkan file .bat yang sudah ada di dalam proyek Anda (BUILD_EXE_ONEFILE.bat atau BUILD_EXE_ONEDIR.bat), atau melakukannya secara manual melalui terminal.   Berikut adalah langkah-langkah lengkapnya:1.Buka Terminal di Direktori Proyek:Persiapan awal.Pastikan Anda berada di dalam folder utama proyek folder-organizer melalui terminal (Command Prompt, PowerShell, atau terminal VS Code).2.Install PyInstaller (Jika Belum Ada):Opsional jika belum terinstall.Jika dependensi belum lengkap, Anda bisa menjalankan file INSTALL_DEPENDENCIES.bat atau menjalankan perintah berikut di terminal:Bashpip install pyinstaller
Verifikasi: Ketik pyinstaller --version di terminal untuk memastikan bahwa PyInstaller sudah terpasang dengan benar.3.Jalankan Proses Build ke .exe:Pilih salah satu metode.Anda memiliki dua cara untuk membuat file .exe:Cara Mudah (Menggunakan file .bat):
Cukup klik dua kali pada file BUILD_EXE_ONEFILE.bat (jika ingin semua file terbundel menjadi satu file .exe) atau BUILD_EXE_ONEDIR.bat (jika ingin dalam bentuk folder berisi file .exe dan dependensinya).Cara Manual (Melalui Terminal):Jika file utama aplikasi Anda adalah main.py atau app.py, jalankan perintah berikut (contoh untuk one-file dengan ikon kustom):Bashpyinstaller --onefile --noconsole --icon=assets/icons/icon.ico main.py
(Ganti main.py dengan app.py jika file utama Anda bernama app.py).4.Cek Hasil File .exe:Verifikasi akhir.Setelah proses build selesai (dituliskan "Completed successfully" di terminal), buka folder proyek Anda. Anda akan melihat folder baru bernama dist di dalamnya. File .exe aplikasi Anda akan berada di dalam folder dist tersebut.Verifikasi: Klik dua kali pada file .exe tersebut untuk memastikan aplikasi berjalan normal tanpa error.
